# To Do app

Build a very basic habit tracker web app.
 
- Email and password sign-up and sign-in. Each user sees only their own habits.
- Add a habit (name, max 100 characters) and delete a habit.
- Today screen: list my habits. One tap marks a habit done for today, and a second tap undoes it.
- Show the current streak (days in a row done) next to each habit.
- Works on phone and desktop. Data is stored in PostgreSQL.
 
Out of scope: reminders, history views, stats, sharing, editing past days.

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a FastAPI service. No architecture had been approved
  when this repository was created, so it starts with its health check and
  nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest
ruff check .
ruff format .
```

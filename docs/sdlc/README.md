# To Do app — SDLC Documentation

> Maintained by QuorQ AI SDLC. Text between `sdlc:auto` markers is regenerated; anything outside them is yours and is kept.

<!-- sdlc:auto:start overview -->
Build a very basic habit tracker web app.
 
- Email and password sign-up and sign-in. Each user sees only their own habits.
- Add a habit (name, max 100 characters) and delete a habit.
- Today screen: list my habits. One tap marks a habit done for today, and a second tap undoes it.
- Show the current streak (days in a row done) next to each habit.
- Works on phone and desktop. Data is stored in PostgreSQL.
 
Out of scope: reminders, history views, stats, sharing, editing past days.

**Documentation version:** v7
